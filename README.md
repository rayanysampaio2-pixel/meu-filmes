# Meu Filmes — APK pronto para compilação

Este projeto já é um aplicativo Android nativo. Para obter o APK sem instalar Android Studio, envie esta pasta para um repositório GitHub e abra **Actions → Gerar APK Meu Filmes → Run workflow**. O arquivo `app-debug.apk` aparecerá em **Artifacts**.

Use somente playlists e streams para os quais você tenha autorização.
